# Shaik Rihan Basha — Portfolio

A recruiter-focused portfolio built from the uploaded resume.

## Stack
- React 19
- Vite
- Tailwind CSS v4
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Resume
Place your PDF as `public/resume.pdf` so the Download résumé button works.

## Notes
The content is grounded in the supplied resume. GitHub and LinkedIn use the links present in the resume; no project/demo URLs were invented.
